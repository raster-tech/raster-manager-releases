# Raster Manager

**Keeps track of every piece of gear across all your shows.**

This repository holds installers only. The first installer will appear on the
[**Releases**](../../releases) page.

## What it does

- Shows all your shows in one place.
- Reads each show's gear from its Google Sheet, one record per item.
- Links to Raster Run, so you can mark an item verified once Raster Run has seen it live.
- Keeps everything on your own computer.

## Install

**Windows 10 or 11.** Early beta, free during the beta.
